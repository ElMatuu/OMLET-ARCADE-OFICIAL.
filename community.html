Instalación sencilla

Empezá desde el dispositivo que tengas.

Hasta que se publiquen los APK y el instalador de Windows, estas son las formas honestas de acceder sin descargar archivos de terceros.

▣

Android y tablets

  1. Abrí Chrome y entrá a PlayVerse.
  2. Iniciá sesión o creá tu cuenta.
  3. En el menú del navegador, elegí Instalar aplicación o Agregar a pantalla principal si aparece.
  4. Confirmá. El acceso quedará en tu pantalla de inicio.
El APK nativo todavía no se ofrece desde esta página. No descargues APKs de fuentes desconocidas que digan ser PlayVerse.
▤

Windows 10 y 11

  1. Abrí Edge o Chrome y entrá a PlayVerse.
  2. En Edge, abrí el menú Aplicaciones; en Chrome, buscá la opción Instalar página como aplicación.
  3. Confirmá la instalación y abrí PlayVerse desde el menú Inicio.
  4. Para usarlo, mantené actualizado el navegador.
El instalador .exe todavía no se ofrece. Se habilitará cuando el build de Windows esté probado y adjuntado a una versión oficial.
¿PlayVerse es la aplicación oficial de Omlet Arcade?

No. PlayVerse es un proyecto independiente que busca ofrecer una experiencia social gamer propia, inspirada en patrones de navegación de plataformas de comunidad.

¿Dónde descargo el APK o el .exe?

Los enlaces aparecerán aquí cuando los paquetes oficiales estén compilados, probados y publicados. No mostramos botones falsos ni archivos sin verificar.

¿La página se actualizará?

Sí. Esta página forma parte del mismo repositorio y se actualizará con cada publicación del sitio. Los cambios publicados se sirven desde el servidor.

¿Puedo registrarme ahora?

Sí, podés abrir la aplicación web desde el botón de acceso. El registro requiere que el servicio y su base de datos estén disponibles.
